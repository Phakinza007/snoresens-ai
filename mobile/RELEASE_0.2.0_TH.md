# Snoresens AI 0.2.0 (build 2)

แอป iPhone แบบ native ใช้โมเดลรุ่น 2 เดิมบนเครื่อง การเปลี่ยนครั้งนี้ปรับการใช้งานและการเก็บข้อมูล ไม่ได้เปลี่ยนโมเดลหรือยืนยันว่าแยกหายใจ/กรนแม่นขึ้น

## ใช้งาน

1. เปิดแอป อนุญาตไมโครโฟน แล้วกด **เริ่มบันทึกคืนนี้**
2. ระหว่างอัดมีเวลาบันทึกและสถานะ **พักการบันทึก / บันทึกต่อ / จบและวิเคราะห์** ตั้งค่า native background audio และการเข้าถึงไฟล์ขณะล็อกจอแล้ว
3. หากมีสายโทรเข้า ระบบเสียงของ iOS อาจพักการอัด และกลับมาอัดต่อเมื่อระบบอนุญาต หากยังพักอยู่ ให้เปิดแอปตรวจสถานะและกด **บันทึกต่อ** การเปลี่ยนอุปกรณ์เสียงตั้งให้พักเพื่อไม่เปลี่ยนไมโครโฟนโดยไม่ตรวจสอบ
4. กด **จบและวิเคราะห์** ไฟล์ยาวอ่านและประมวลผลทีละไม่เกิน 5 นาที เมื่อออกจากแอปจะพักการวิเคราะห์ กลับมากดปุ่มรูปกราฟในประวัติเพื่อทำต่อ ส่วนที่เสร็จแล้วไม่ต้องคำนวณใหม่
5. แตะประวัติเพื่อดูรายงาน หากมีหลายส่วนจะเลือกส่วนที่จะฟังได้ เวลาในกราฟของแต่ละส่วนเริ่มที่ 00:00 ของส่วนนั้น
6. ส่งออก JSON และ Timeline CSV จากรายงาน หรือส่งออกสรุปประวัติจากปุ่มแชร์หน้าแรก เสียง WAV เต็มอยู่ใน **Files → On My iPhone → Snoresens AI → Snoresens** แชร์เสียงผ่านแอป Files ได้

ประวัติ เสียง และผลวิเคราะห์เก็บใน Documents ของแอป เปิดปิดแอปแล้วยังอยู่ การลบต้นฉบับจากหน้าแอปมีข้อความยืนยันและลบส่วนย่อยที่เกี่ยวข้องด้วย ข้อมูลจะหายเมื่อถอนแอปหรือเมื่อผู้ใช้ลบไฟล์จาก Files จึงควรส่งออกข้อมูลที่ต้องการเก็บระยะยาว

## ขอบเขตที่ตรวจสอบได้

- ทดสอบอัตโนมัติครอบคลุมการกดซ้ำ การปฏิเสธสิทธิ์ การพัก/ต่อ การหยุดที่ผิดพลาด การเก็บและเปิดประวัติใหม่ และการวิเคราะห์ต่อหลังออกจากแอป
- ทดสอบไฟล์ยาว 601 วินาที แบ่ง 300 + 300 + 1 วินาที สรุปสัดส่วนกรนถ่วงน้ำหนักตามระยะเวลา เก็บช่วงท้ายครบ ไม่อ่าน WAV ข้ามคืนทั้งหมดเข้าหน่วยความจำพร้อมกัน
- ตรวจ UI ของ component อัดเสียงที่ 390 px และ 320 px พร้อมตัวอักษรขยาย 2 เท่า ภาพจาก widget test เป็นสถานะจำลอง ไม่ใช่หลักฐานจาก iPhone จริง
- ตรวจ archive หลัง build ให้เป็น arm64 / iPhoneOS รุ่นแอป 0.2.0 มี background audio, microphone description และ Files integration พร้อมตรวจ hash โมเดล v2
- **ยังต้องทดสอบการรับเสียง ล็อกจอ สายโทรเข้า ส่งออก และใช้งานต่อเนื่องบน iPhone จริง** การตั้งค่าและการ build ไม่ใช่หลักฐานว่าการอัดข้ามคืนผ่านแล้ว

## ทดสอบบนโทรศัพท์หลังติดตั้ง

| ขั้นตอน | สิ่งที่ควรเห็น |
| --- | --- |
| อัด 30 วินาที ล็อกจอ 60 วินาที เปิดจอแล้วอัดอีก 30 วินาที กดจบ | ได้เสียงประมาณ 2 นาที รวมเสียงที่ทำระหว่างล็อกจอ ฟังย้อนยืนยันได้ |
| พัก 10 วินาทีแล้วอัดต่อ | ช่วงพักไม่ถูกเพิ่มเป็นเสียงเงียบใน WAV; เวลาอัดและความยาวเสียงไม่รวมช่วงพัก |
| รับสายโทรศัพท์ระหว่างอัดแล้ววางสาย | ตรวจสถานะพัก/อัดต่อ หากไม่กลับมาให้กดบันทึกต่อ แล้วฟังไฟล์ว่ามีเสียงหลังวางสาย |
| อัดและวิเคราะห์เสร็จ ปิดแล้วเปิดแอป | ประวัติและเสียงยังเปิดได้ |
| ออกจากแอประหว่างวิเคราะห์ไฟล์ยาว | กลับมากดวิเคราะห์ต่อ ส่วนที่เสร็จแล้วยังอยู่ |
| ส่งออก JSON/CSV และแชร์ WAV ผ่าน Files | ไฟล์เปิดได้ในแอปอื่นและระยะเวลาตรงกับรายงาน |
| อัดแบบล็อกจอ 10 นาที แล้วทดสอบระยะยาวขึ้น | ตรวจเสียงจริงและระยะเวลา ก่อนใช้ข้ามคืน |

ไม่อัดต่อหลังผู้ใช้ force-quit แอปหรือรีสตาร์ตเครื่อง เมื่อเปิดใหม่จะพบรายการค้างและเก็บไฟล์ที่มีไว้ แต่ไฟล์ WAV ที่ header เสียจากการถูกปิดกลางคันอาจยังวิเคราะห์ไม่ได้ ไม่ลบทิ้งอัตโนมัติ

WAV mono 16 kHz PCM16 ใช้พื้นที่ประมาณ 115 MB ต่อชั่วโมง มีไฟล์ส่วนย่อยและ JSON เพิ่มระหว่างวิเคราะห์ ต้องเผื่อพื้นที่เพิ่มจากต้นฉบับ การตัดเป็น 5 นาทีอาจแยกเหตุการณ์กรนที่คร่อมรอยต่อ จึงระบุจำนวนเหตุการณ์รวมว่าเป็นผลรวมของส่วนย่อย ไม่ใช่จำนวนเหตุการณ์ที่ต่อเนื่องตลอดคืน ไม่มีการวัด sleep stage หรือวินิจฉัยหยุดหายใจ
