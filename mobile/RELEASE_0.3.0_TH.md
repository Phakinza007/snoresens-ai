# Snoresens AI 0.3.0 (build 3) — หน้าตาเดียวกับเว็บ

ปรับแอป Flutter ให้ตามเว็บ Snoresens ปัจจุบัน: การ์ดพระจันทร์ หน้าแรก เมนูล่าง หน้ารายงาน ประวัติ โปรไฟล์ และขั้นตอนเตรียม/ยินยอม/บันทึก ใช้ Noto Sans Thai และ Lucide SVG ชุดเดียวกัน ไม่เปลี่ยนหัวจำแนกเสียงกรนรุ่น 2 และไม่เปลี่ยนการตั้งค่าอัดเบื้องหลังจาก 0.2.0

## ใช้งานที่เพิ่มและปรับ

- หน้าแรกและเมนูล่าง 4 หน้าเหมือนเว็บ เลือกไฟล์ WAV หรือลองเสียงตัวอย่างที่รวมในแอปได้ เสียงตัวอย่างมีป้ายกำกับและรันโมเดลจริงบนโทรศัพท์เมื่อผู้ใช้กด
- ขั้นตอนเตรียมอุปกรณ์และยินยอมก่อนขอไมโครโฟน หน้าอัดสีกรมท่า แสดงเวลาจริงที่แอปติดตาม พัก/ต่อ/จบ และกลับหน้าหลักโดยอัดต่อได้ ไม่มีการสร้างคลื่นปลอมให้ดูเหมือนระดับเสียงที่วัดได้
- รายงานมีสรุปสัดส่วนกรน ระยะเวลา เลือกฟังช่วงเสียง ซูม 20 ms และรายละเอียดการวัด พร้อม JSON / Timeline CSV / WAV ส่วนที่เปิดอยู่ รายการเหตุการณ์ยาวแบ่งหน้าเพื่อไม่สร้าง widget ทั้งหมดในครั้งเดียว
- เช็กลิสต์ตอนเช้า 5 ข้อตามกฎของเว็บ บันทึกคำตอบแยกตามการบันทึกต้นฉบับ ส่วนย่อยของไฟล์ยาวใช้คำตอบร่วมกัน พร้อมแสดงแนวโน้มในประวัติ ไม่ใช้เสียงตัวอย่างไปปนในประวัติเช็กลิสต์ของการบันทึกจริง
- โปรไฟล์แก้ชื่อได้ในเครื่อง เปิดคำแนะนำ/ความเป็นส่วนตัว/คำอธิบาย/สิทธิ์ใช้งาน และลบข้อมูลทั้งหมดหลังยืนยันได้
- ยังคงเสียงและประวัติจาก 0.2.0 ใน Documents, การวิเคราะห์ทีละ 5 นาที, การทำต่อจากจุดค้าง และสรุปการบันทึกแบบถ่วงน้ำหนัก การวิเคราะห์ใหม่แบบละเอียดคำนวณใหม่จริง ส่วนปุ่มวิเคราะห์ต่อใช้ส่วนที่ทำเสร็จแล้ว

## ความต่างที่ตั้งใจจากเว็บ

ข้อความในแอประบุการทำงานบน iPhone และการเก็บในพื้นที่แอป แทน IndexedDB/เบราว์เซอร์ มี safe area ของ iOS และไม่มี sidebar สำหรับคอมพิวเตอร์ ไฟล์ยาวมีหน้าสรุปรวมกับตัวเลือกส่วนย่อยเพื่อจำกัดหน่วยความจำ พื้นที่ภาพตกแต่งปรับตามตัวอักษรใหญ่เพื่อไม่บังข้อความ

เช็กลิสต์เป็นกฎทดลองของโครงการ ยังไม่ผ่านการตรวจสอบทางคลินิก เกณฑ์รวม 10% และ 3 ใน 7 การบันทึกไม่ได้เป็นเกณฑ์วินิจฉัยโรค ตัวเลขเสียงกรนใช้เวลาที่บันทึก ไม่ใช่เวลาที่หลับ แหล่งอ้างอิงสัญญาณการหายใจผิดปกติ: [AASM](https://sleepeducation.org/sleep-disorders/obstructive-sleep-apnea/). โมเดลไม่ได้ตรวจยืนยันการหยุดหายใจจากเสียงนี้

## การตรวจสอบ

เทียบภาพจากเว็บจริงกับ widget ที่ 390 px และทดสอบ 320 px พร้อมตัวอักษรใหญ่ ตรวจการกดยินยอม อัด พัก/ต่อ จบ เปิดประวัติหลังสร้างหน้าจอใหม่ ตอบเช็กลิสต์ แก้ชื่อ ยกเลิกและยืนยันการลบ ผลสูตรทดลองเทียบ fixture ของเว็บ 864 กรณีเช็กลิสต์และ 42 กรณีคะแนนเสียง รวมขอบเขตกรน 20 ms และการวิเคราะห์ไฟล์ยาว

ภาพพรีวิวเป็นภาพ render จาก Flutter และสถานะทดสอบ ไม่ใช่ screenshot จาก iPhone จริง รายงานในภาพใช้ผลของเสียงตัวอย่างสาธารณะจากเว็บเพื่อเทียบหน้าตา ไม่ใช่หลักฐานความแม่นยำของโมเดลบน iPhone

การอัดขณะล็อกจอ สายโทรเข้า การฟังและ export บน iPhone จริงยังต้องตรวจบนอุปกรณ์ ดู [ขั้นตอนทดสอบ](RELEASE_0.2.0_TH.md) การ build ผ่านไม่ยืนยันการอัดข้ามคืน และแอปไม่อัดต่อหลัง force-quit
