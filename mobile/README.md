# Sanor mobile

แอป Flutter สำหรับ Android/iPhone ใช้ YAMNet TFLite และ snore classifier ที่ฝึกไว้แล้ว ประมวลผล WAV บนมือถือโดยตรง ไม่มี API หรือการส่งไฟล์เสียงออกไป

## สร้างแอป

ติดตั้ง [Flutter SDK](https://docs.flutter.dev/install) และเครื่องมือ Android Studio หรือ Xcode ตามระบบที่จะรัน จากโฟลเดอร์ `mobile`:

```bash
./setup.sh
flutter run
```

`setup.sh` สร้างโฟลเดอร์แพลตฟอร์ม Android/iOS, คัดลอกไฟล์โมเดล, เพิ่มสิทธิ์ไมโครโฟน และติดตั้งแพ็กเกจ Dart จากนั้นเชื่อมโทรศัพท์จริงหรือเปิด emulator แล้วรัน `flutter run`

แอปรองรับ WAV PCM 16-bit 16 kHz mono/stereo สำหรับการเลือกไฟล์ ปุ่มอัดเสียงขอ 16 kHz mono WAV จากไมโครโฟน ถ้าอุปกรณ์บันทึกเป็นรูปแบบอื่น แอปจะแจ้งว่าอ่านไฟล์ไม่ได้ ผลลัพธ์คือสัดส่วนเวลาที่พบกรน นาทีกรนต่อชั่วโมงที่อัด และจำนวนช่วงกรนต่อชั่วโมง ไม่ใช่การวินิจฉัยโรคหรือชั่วโมงที่หลับจริง

สถานะการตรวจ: ซอร์สแอปยังไม่ได้ build เพราะเครื่องนี้ไม่มี Flutter SDK; ต้องรัน `flutter analyze` และทดลองอัดเสียงบนอุปกรณ์เป้าหมายหลังติดตั้ง SDK โดยเฉพาะการทำงานขณะล็อกหน้าจอ ซึ่งยังไม่ได้รองรับหรือทดสอบ


## Audio pattern features (source added; build pending)

The source now calculates RMS/dBFS, quiet gaps between snoring segments, dominant frequency, spectral centroid, and snoring-segment start intervals. It includes local playback with seeking, bounded timeline tracks, paginated events, a baseline percentage comparison, removal of temporary review copies, and JSON/timeline CSV save dialogs. The measurement definitions are in [AUDIO_ANALYSIS.md](../AUDIO_ANALYSIS.md). Playback adds `audioplayers` (MIT); the FFT implementation is local Dart code with no extra numerical dependency.

Run after installing the Flutter SDK:

```bash
./setup.sh
flutter analyze
flutter test
flutter run
```

`test/audio_patterns_test.dart` uses fixtures generated by Python to compare quiet-gap boundaries and rhythm, plus synthetic tone/silence checks. These tests have not run in the current environment because Flutter/Dart are absent. The app still needs Android/iOS build and physical-device verification. Background recording is not implemented. Results are held in memory, and playback copies use temporary device storage; export before closing the app if you want to retain the measurements.
