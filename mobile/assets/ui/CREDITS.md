# Shared Snoresens web/mobile assets

- Noto Sans Thai variable TTF copied unchanged from `web/snoresens/thai.ttf`; SIL Open Font License in FONT-LICENSE.txt.
- Lucide Static 0.468.0 SVGs copied unchanged from `web/snoresens/icons/`; ISC License in LUCIDE-LICENSE.txt.
- sample.wav is the existing web `test_snore_16k.wav`, converted to WAV / 16 kHz from **Tongue base snoring** by Langenbergstefan, Wikimedia Commons, **CC BY-SA 3.0**: https://commons.wikimedia.org/wiki/File:Tongue_base_snoring.ogg . License: https://creativecommons.org/licenses/by-sa/3.0/ . The sample is labeled in the app and analyzed by the native model when requested.
- Moon and bedside artwork reproduce the web's CSS geometry using native Canvas/layout; they are not exported Figma layers. The home wave is decorative, and the recording waveform is a flat indicator, not simulated microphone amplitude.
- Flutter and dependency license notices are accessible from Profile → Snoresens AI 0.3.0 → Licenses. The font and icon notices are registered there too.
